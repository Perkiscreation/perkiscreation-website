PERKISCREATION – VERSION 7

Diese Version baut auf der bisherigen Version 6 auf.

GEÄNDERT
- Startseite/Hero bleibt unverändert.
- Zwei echte Vorher-Nachher-Slider auf der Startseite:
  1. Pfingstrosen – frischer Strauß / fertiges Resin-Hexagon in der Hand
  2. Luftgetrockneter Strauß – getrockneter Strauß / Resin-Bogen
- Die vom Kunden bereitgestellten Fotos werden direkt verwendet.
- Die Slider funktionieren mit Maus, Touchpad und auf dem Smartphone per Finger.
- Kleine zusätzliche Info-Box als optisches Detail ohne doppelte Verkaufsaussage.
- FAQ um die wichtige Frage zu bereits luftgetrockneten Sträußen ergänzt.
- Bestehende Inhalte, Produkte, Kontakt und rechtliche Seiten bleiben erhalten.

INSTALLATION
1. VS Code: laufenden Server mit Strg + C stoppen.
2. Sicherungskopie des bisherigen Ordners erstellen.
3. Inhalt dieses ZIP-Ordners vollständig in den bisherigen Projektordner kopieren.
4. Dateien im Ziel ersetzen.
5. VS Code im Projektordner öffnen.
6. npm install (falls nötig).
7. npm run dev.
8. http://localhost:3000 öffnen und Strg + F5 drücken.
