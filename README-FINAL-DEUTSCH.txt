INSTALLATION
1. In VS Code den laufenden Server mit Strg + C stoppen.
2. Eine Sicherungskopie des bisherigen Ordners erstellen.
3. Diese ZIP vollständig entpacken.
4. Alle Dateien aus dem entpackten Ordner kopieren.
5. In C:\Users\timot\perkiscreation-website einfügen.
6. "Dateien im Ziel ersetzen" auswählen.
7. In VS Code ausschließlich C:\Users\timot\perkiscreation-website öffnen.
8. Im Terminal npm install eingeben.
9. Danach npm run dev eingeben.
10. http://localhost:3000 öffnen und Strg + F5 drücken.
